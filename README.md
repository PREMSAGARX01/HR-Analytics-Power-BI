📌 Project Overview

The HR Analytics Dashboard is an interactive business intelligence project developed using Microsoft Power BI.

The project analyzes human resource data to provide insights into workforce distribution, employee attrition, compensation structures, recruitment activities, and employee performance.

It transforms raw HR datasets into meaningful visual reports that support workforce monitoring and data-driven decision-making.

🎯 Project Objectives

- Analyze workforce composition and employee distribution.
- Identify employee attrition patterns and contributing factors.
- Understand salary, bonus, and variable pay structures.
- Evaluate employee performance and promotion trends.
- Monitor recruitment pipeline activity.
- Present key HR metrics through an executive dashboard.

📊 Dashboard Preview

The project contains five interactive dashboard pages.

1. Workforce Overview

Analyzes the overall workforce structure.

Key Insights:

- Total and active employees
- Gender distribution
- Department-wise workforce
- Employee distribution by city
- Job-level distribution
- Average salary

2. Attrition & Retention Analysis

Explores employee attrition patterns across different workforce segments.

Key Insights:

- Employees with attrition records
- Attrition by reason
- Department-wise attrition
- Gender-wise attrition
- Job-level attrition

3. Compensation & Salary Analytics

Examines employee compensation components and salary distribution.

Key Insights:

- Average base salary
- Average bonus
- Average variable pay
- Compensation component breakdown
- Department-wise compensation analysis

4. Performance & Promotion Analytics

Evaluates employee performance and promotion information.

Key Insights:

- Employees with performance records
- High performers
- Performance rating distribution
- Promotion status distribution
- Average performance rating by department
- High performers by department

5. Executive HR Summary

Provides a consolidated overview of important HR metrics.

Key Insights:

- Total employees
- Active employees
- Average salary
- High performers
- Employees with attrition records
- Department-wise workforce distribution
- Attrition reasons
- Recruitment pipeline
- Department health scorecard
